KisanDwaar — Farmer Portal

This release contains the Farmer Portal only. The Employee Portal is marked Coming Soon.

Run:
  node server.js
Then open:
  http://localhost:3000

There are NO demo IDs or demo passwords.
Create a farmer account from the sign-in screen, then sign in with the registered mobile number and password.

Flow:
Welcome / Farmer Sign In → Create Account (if needed) → Language (English / Telugu / Hindi) → Farmer Dashboard → Centre → Slot → Payment → Booking tracking / cancellation.

The payment is a demo booking-fee flow; no real money is charged.
